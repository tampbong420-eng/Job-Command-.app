# Job Command

Field-ops dashboard for Job Command. The **Boss** Command screen is the crew
dispatch desk:

- **CREW** header instead of a personal greeting
- Swipeable employee rolodex with live hours, clock status, and weekly schedule
- **Edit Hours** calendar for each crew member's week
- Combination-lock job tumbler that cycles **active jobs only**
- **Get Directions** opens the active property with Street View and Google Maps
- Live Google Map at the bottom of the crew desk
- Semantic job colors: new leads red, pending orange/yellow, active light green, completed charcoal

The Employee view stays on the existing home layout and is not the focus of
this pass.

```bash
npm install
npm test
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and use the **BOSS** tab.
