# Job Command — compiled context

Durable memory for every agent on this project. Update the log when work lands. Do not delete finished decisions.

## Product

Job Command is a phone-first shop desk for **Top Gun Painting** in Hot Springs, AR. Chrome is the shop (logo/monogram, company name, tickets like `TGP-2041`), not a generic SaaS mark.

Owner in product copy / actor: **Dana Reeves**. Real owner talking to agents: **Eric Stlawrence**.

Five dock tabs: **Command, Crew, Schedule, Pay, Company**. Field crew only get Command, Crew, Schedule. Office PIN / 4-digit last-four of phone; office fallback `1001` if no phone. Session cookie 30 days.

### Theme / Style A

Eric asked for a unified green frame on every page, then **“No go back.”** That global overwrite was reverted (`e14a285`). Default layout is restored.

**Style A** is a selectable dark HUD theme from six reference overlay images (stream-style frames: chamfered corners, hatch marks, corner brackets, inner glow, top/bottom HUD bars). Rules:

- Default dark/light **untouched** when Style A is off
- Overlay scoped to `.app-shell[data-style="a"]`
- Five customizable colors in Company → App look (`ThemePicker`)
- Persistence: `localStorage` keys `jc-style-a`, `jc-style-a-colors`
- Immediate preview: **`/?style=a`** (turns on and persists). `/?style=off` turns it off
- HUD component: `components/command/StyleAHud.tsx`
- CSS: block at the end of `app/globals.css`
- Logic: `lib/style-a.ts`, `hooks/use-style-a.ts`
